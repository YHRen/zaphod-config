# Source index and provenance

Local copies are kept here so the electrical references used by the project
remain available. They are reference material, not project-authored works;
their original copyright and licensing terms still apply.

`SHA256SUMS` records the archived files' hashes so accidental changes can be
detected.

## Local documents

### `holyiot-18010-nrf52840-datasheet.pdf`

- Title: *Holyiot-18010-NRF52840 Datasheet*, version 1.
- Publisher: Shenzhen Holyiot Technology Co., Ltd., issued 2018-01-01.
- Retrieved from the Robu distributor mirror:
  <https://robu-prod-media.s3.ap-south-1.amazonaws.com/uploads/2025/04/R228997-18010-nRF52840-datasheet.pdf>
- Relevant content: module dimensions, pad locations, complete pin assignment,
  PCB mounting guidance, and absolute maximum ratings.
- The embedded PDF metadata says `MDBT50Q-U1M_Version B` and names Raytac as
  author, but the visible cover and document pages consistently identify
  Shenzhen Holyiot and model `Holyiot-18010-NRF52840`.

### `zaphod-v1-schematic.pdf`

- Title: The Zaphod, schematic revision v0.1.2.
- Generated by KiCad 6.0.4 on 2022-04-01.
- Original local source:
  `/Users/yren/github/yhren/zaphod/zaphod-v1_scheme.pdf`.
- Relevant content: Holyiot nRF52840 pins, Sharp display signals, display
  connector, XC6206 3.3 V regulator, USB VBUS, battery charger, and matrix.

### `tpm754-datasheet.pdf`

- Title: *TPM754 Microcontroller with TrackPoint microcode from IBM*.
- Publisher: Philips Semiconductors, preliminary specification, 1997-12-03.
- Retrieved from:
  <https://github.com/alonswartz/trackpoint/blob/master/datasheets/tpm754.pdf>
- Relevant content: reference TrackPoint schematic, RESET behavior, 5 V
  electrical characteristics, pin descriptions, and PS/2 pull-ups.

### `figures/tpm754-reference-schematic.png`

- Original file name: `reset.png`.
- Retrieved from:
  <https://github.com/alonswartz/trackpoint/blob/master/datasheets/reset.png>
- This is a reference-schematic image containing the 2.2 uF/100 kOhm
  power-on-reset circuit and 4.7 kOhm PS/2 pull-ups.
